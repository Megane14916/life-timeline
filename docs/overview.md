# life-timeline Overview

## 概要

**life-timeline** は、PC・スマートフォン上で発生した日々の行動を自動で収集し、時系列で振り返るための個人向けライフログアプリです。

「何時にどこへ行ったか」「どんな写真を撮ったか」「スマホやPCでどのアプリを使っていたか」といった情報を、1つのタイムライン上で確認できることを目指します。

AIによる要約や分析は必須機能とせず、まずは **記録をできるだけ自動で残し、長期間安全に管理できること** を重視します。

## 主な記録対象

### Android

- 位置情報
- 撮影した写真のメタデータ
- 写真の軽量サムネイル
- アプリ使用履歴
- 将来的には手動イベント・メモ

### Windows PC

- アプリ使用履歴
- アクティブウィンドウ
- Webサイト利用履歴
- ActivityWatch から取得できる作業記録

## 基本方針

- PCをデータ管理の中心とする
- Androidはデータ収集と一時保存を担当する
- Android → PC の同期は Tailscale 経由で行う
- 原本写真はPCへ送らず、ライフログ表示用のサムネイルのみ送る
- PC側のデータは SQLite とローカルファイルに保存する
- クラウドを必須としない
- 独自の暗号・認証方式はできるだけ実装しない
- 収集したデータは、将来アプリを使わなくなっても取り出せる形にする

## 想定する利用イメージ

ある1日を開くと、以下のような情報を時系列で確認できます。

```text
2026/09/03

09:10  PC: Chrome
09:32  PC: VS Code / life-timeline
10:15  自宅を出発
10:52  東京駅周辺に到着
10:55  写真を2枚撮影
11:03  Android: Google Maps
11:20  丸の内周辺に移動
13:42  写真を1枚撮影
14:10  Android: YouTube
16:30  PC: VS Code
```

## MVP

最初のMVPでは、以下を実現します。

1. Androidからアプリ使用履歴を取得する
2. Android内に一時保存する
3. Tailscale経由でPCへ送信する
4. PCのSQLiteへ保存する
5. Reactのタイムライン画面で確認する

その後、写真・位置情報・ActivityWatch連携を順次追加します。

## 非目標

初期段階では以下を目的としません。

- SNS機能
- 他ユーザーとの共有
- クラウド同期
- AIによる自動分析
- 写真原本のバックアップ
- iOS対応
- 商用サービスとしての公開

これらは、コアとなるライフログ収集・保存・表示が安定した後に検討します。
